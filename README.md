# SmileCare Dental Clinic

Frontend website for SmileCare Dental Clinic, Indore, built with Next.js and deployed on Netlify.

- `npm install` then `npm run dev` to run locally.
- Appointment requests open WhatsApp with the details pre-filled. Set `NEXT_PUBLIC_WHATSAPP` (e.g. `919876543210`) to change the receiving number.
